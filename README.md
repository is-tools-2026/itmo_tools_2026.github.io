# ☕ Кофейня Стипендия

Веб-сайт студенческой кофейни «Стипендия» — уютная кофейня рядом с университетом, где каждый найдёт свой любимый напиток.

## Сайт развернут на Github pages

https://is-tools-2026.github.io/itmo_tools_2026.github.io/index.html

## О проекте

Проект представляет собой статический сайт из трёх страниц:

- **О нас** — информация о кофейне, история, расположение на карте, часы работы и форма обратной связи.
- **Меню** — каталог напитков и десертов с ценами и кнопкой добавления в корзину.
- **Корзина** — выбранные позиции, изменение количества, оформление заказа с подтверждением и формой оплаты.

В шапке сайта есть переключатель режима, который меняет поведение страниц. Состояние переключателя сохраняется между визитами.

## Технологии

- **HTML** — разметка страниц
- **CSS** — оформление и адаптивная вёрстка
- **JavaScript (vanilla)** — логика страниц, без сторонних библиотек
- **localStorage** — хранение корзины и настроек

## Возможности

- Каталог из 10 позиций: кофе, чай, какао и десерты.
- Добавление товаров в корзину с сохранением в `localStorage`.
- Счётчик позиций в шапке, общий для всех страниц.
- Изменение количества и удаление позиций в корзине.
- Подсчёт итоговой суммы заказа.
- Диалог подтверждения заказа.
- Форма оплаты с валидацией полей.
- Форма обратной связи с валидацией.
- Интерактивная карта с отметкой расположения кофейни.
- Переключатель режима в шапке сайта.

## Запуск локальный

Сайт статический, для работы достаточно любого локального HTTP-сервера. Например:

```bash
python3 -m http.server 8080
```

Затем откройте в браузере: <http://localhost:8080>

## Использование

1. Откройте главную страницу, чтобы узнать о кофейне и найти её на карте.
2. Перейдите в «Меню» и добавьте понравившиеся позиции в корзину.
3. Откройте «Корзину», проверьте заказ и оформите его.
4. Заполните форму оплаты и подтвердите заказ.
